## Bookshelf-Updater

<sub><sup>Made entirely in Godot</sup></sub>


Edits a JSON file for keeping track of books you've read, are reading, or are planning to read.

Also copies/renames images for the book covers

Creates a bookshelf.json file structured as {"current":\[], "up-next":\[], "completed":\[]}
